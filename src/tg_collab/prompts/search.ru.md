# Быстрый поиск каналов в Telegram

Владелец ведёт Telegram-канал @$USERNAME. Найди публичные каналы-ровесники для одного личного,
честного предложения о сотрудничестве.

- Темы: $TERMS
- Хэштеги: $HASHTAGS. Домены ссылок: $DOMAINS.
- Язык: $LANGUAGE. Регион: $REGION.
- Размер: $SIZE_RANGE. Ставь этот диапазон в приоритет, но не выбрасывай подходящие по теме
  каналы вне его: инструмент оценит размер отдельно.

Правила:
- Сделай не больше 3 веб-запросов. Не открывай страницы `t.me`; инструмент сам проверит каналы.
- Остановись через 90 секунд.
- Верни 5-10 каналов (не больше 10 каналов), а если совсем мало — хотя бы 3.
- Верни ТОЛЬКО JSON-массив, без пояснений: [{"username": "name", "why": "одна фраза"}].
  `username` — реальный публичный username Telegram без `@`; никогда не выдумывай его.

Инструмент и агент ничего не отправляют в Telegram и никому не пишут. Не вступай в каналы.
Этот бриф лишь готовит список для человека-владельца.
